🏗️ Архитектура проекта

Обзор

METAIMPERIYA — это социальная сеть, построенная на HTML5, CSS3, Vanilla JavaScript и Firebase. Проект полностью адаптивен и работает на всех устройствах.

📌 Ключевые технологии:
  • Frontend: HTML5, CSS3, JavaScript (ES6+)
  • Backend: Firebase (Realtime Database, Auth, Storage)
  • Хостинг: GitHub Pages
