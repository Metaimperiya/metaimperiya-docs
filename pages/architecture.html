🏗️ Архитектура проекта

Обзор

METAIMPERIYA — это социальная сеть, построенная на HTML5, CSS3, Vanilla JavaScript и Firebase. Проект полностью адаптивен и работает на всех устройствах.

📌 Ключевые технологии:
  • Frontend: HTML5, CSS3, JavaScript (ES6+)
  • Backend: Firebase (Realtime Database, Auth, Storage)
  • Хостинг: GitHub Pages
  • Домены: metaimperiya.com, docs.metaimperiya.com

🎨 Frontend

Вся логика интерфейса построена на чистом JavaScript без фреймворков. Это делает проект:

  • Быстрым — нет лишних зависимостей
  • Понятным — код легко читать и менять
  • Гибким — можно добавить любую функциональность
📄 script.js — Основная логика (часть 1: Auth) 
// ================================================================
// AUTH — АВТОРИЗАЦИЯ
// ================================================================

// Подключаем Firebase Auth
const auth = firebase.auth();
const provider = new firebase.auth.GoogleAuthProvider();

// Слушаем изменения состояния авторизации
auth.onAuthStateChanged(user => {
    if (user) {
        // Пользователь вошел
        USER_UID = user.uid;
        USER = user.displayName || user.email || user.uid.slice(0, 8);
        // ... обновляем UI
    } else {
        // Пользователь вышел
        document.getElementById('loginModal').classList.add('open');
    }
});

// Вход через Google
document.getElementById('googleBtn').addEventListener('click', () => {
    auth.signInWithPopup(provider);
});

// Анонимный вход
function loginName() {
    const name = document.getElementById('nameInput').value.trim();
    if (!name) { alert('Введите имя'); return; }
    auth.signInAnonymously();
});

🔥 Backend (Firebase)

Firebase используется для:

  • Аутентификации — Google и анонимный вход
  • Базы данных — все данные хранятся в Realtime Database
  • Хранилища — аватарки пользователей
⚠️ Важно! Все правила безопасности настроены в Firebase Console.
