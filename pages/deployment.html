🚀 Деплой проекта

Обзор

METAIMPERIYA может быть развёрнута несколькими способами. Основные варианты:

📌 Варианты деплоя:
  • GitHub Pages — бесплатно, просто, подходит для статики
  • Vercel — быстрее, поддержка SPA, кастомные домены
  • Netlify — альтернатива Vercel

📦 GitHub Pages

Самый простой способ развернуть статический сайт.

🚀 Деплой на GitHub Pages 
# ================================================================
# ДЕПЛОЙ НА GITHUB PAGES
# ================================================================

# 1. Залей код в репозиторий
git add .
git commit -m "Initial commit"
git push origin main

# 2. Включи GitHub Pages
# Settings → Pages → Source → Deploy from a branch
# Branch: main → / (root) → Save

# 3. Добавь .nojekyll (отключает Jekyll)
# touch .nojekyll
# git add .nojekyll
# git commit -m "Add .nojekyll"
# git push

# 4. Сайт будет доступен по адресу:
# https://username.github.io/repository/
⚠️ Важно! Если сайт не открывается и выдаёт 404 — проверь:
  • Файл index.html лежит в корне репозитория
  • Добавлен файл .nojekyll (отключает Jekyll)
  • В настройках Pages выбрана правильная ветка и папка

⚡ Vercel

Более продвинутый вариант с поддержкой SPA, серверных функций и кастомных доменов.

🚀 Деплой на Vercel 
# ================================================================
# ДЕПЛОЙ НА VERCEL
# ================================================================

# 1. Установи Vercel CLI
npm install -g vercel

# 2. В корне проекта создай vercel.json
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}

# 3. Запусти деплой
vercel
# Следуй инструкциям в терминале

# 4. Продакшн-деплой
vercel --prod

# 5. Сайт будет доступен по адресу:
# https://metaimperiya.vercel.app
📄 vercel.json (полный) 
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ],
  "headers": [
    {
      "source": "/(.*)",
      "headers": [
        {
          "key": "X-Content-Type-Options",
          "value": "nosniff"
        },
        {
          "key": "X-Frame-Options",
          "value": "DENY"
        },
        {
          "key": "X-XSS-Protection",
          "value": "1; mode=block"
        }
      ]
    }
  ]
}

🌐 Кастомный домен

Как привязать свой домен к сайту.

🌐 Настройка кастомного домена 
# ================================================================
# НАСТРОЙКА КАСТОМНОГО ДОМЕНА
# ================================================================

# Для GitHub Pages:
# 1. В репозитории создай файл CNAME с доменом
echo "metaimperiya.com" > CNAME
git add CNAME
git commit -m "Add CNAME"
git push

# 2. В настройках DNS добавь записи:
# A-запись: @ → 185.199.108.153
# A-запись: @ → 185.199.109.153
# A-запись: @ → 185.199.110.153
# A-запись: @ → 185.199.111.153
# CNAME: www → username.github.io

# Для Vercel:
# 1. В панели Vercel → Settings → Domains
# 2. Добавь домен metaimperiya.com
# 3. В DNS добавь CNAME: @ → cname.vercel-dns.com

🛠️ Устранение проблем

❌ Сайт выдаёт 404
  • Проверь, что index.html в корне
  • Добавь файл .nojekyll
  • Перезапусти деплой (Settings → Pages → Save)
  • Подожди 2-3 минуты
⚠️ Не загружаются стили/скрипты
  • Проверь пути: href="style.css" → href="/style.css"
  • Для GitHub Pages используй абсолютные пути с названием репозитория
  • Пример: href="/metaimperiya-docs/style.css"
❌ Не работает Firebase
  • Проверь, что домен добавлен в Authorized domains в Firebase Console
  • Проверь правильность конфигурации Firebase
  • Убедись, что правила безопасности разрешают чтение/запись
